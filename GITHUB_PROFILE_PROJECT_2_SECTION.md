## Project 2 — Construction Change Order and RFI Analytics

[![Executive dashboard](https://raw.githubusercontent.com/ND3404/construction-change-order-rfi-analytics/main/assets/executive-dashboard.png)](https://github.com/ND3404/construction-change-order-rfi-analytics)

**Root-Cause, Cycle-Time, and Impact Analysis for Construction Decision Workflows**

An end-to-end construction analytics case study examining 3,318 RFIs, 1,119 change orders, workflow-event histories, and explicit RFI-to-change relationships across 90 synthetic construction projects.

**Highlights**

- 12.21-day average RFI response and 45.7% on-time performance
- $204.57M approved change value and $88.10M pending exposure
- Transparent project workflow health: 29 Red / 48 Yellow / 13 Green
- Strong project-level association between RFI response and change approval cycle: Pearson r = 0.817
- Excel, SQL, SQLite, Python, Power BI, Tableau, workflow analytics, and responsible AI governance
