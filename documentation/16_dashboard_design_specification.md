# Dashboard Design and Storytelling Specification

## Visual hierarchy

1. Business question and synthetic-data disclosure
2. Executive KPIs
3. Project workflow health
4. Commercial exposure
5. Root-cause and bottleneck evidence
6. Project priority
7. Limitations and next actions

## Number formats

- Currency below $1 million: `$#,##0`
- Portfolio currency: `$0.0M`
- Rates: `0.0%`
- Cycle time: `0.0 days`
- Counts: `#,##0`
- Correlations: `0.000`

## Status communication

Use color and text: Red, Yellow, and Green. Do not rely on color alone.

## Public image use

Use the executive dashboard as the primary GitHub and LinkedIn image. Use the workflow-analysis image in detailed case-study pages. Avoid using raw-data screenshots as the primary visual.
